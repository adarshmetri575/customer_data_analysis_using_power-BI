# Customer Data Analysis – Power BI

## Project Overview
This project analyzes customer shopping data using Power BI to understand purchasing behavior, customer demographics, product performance, payment preferences, and shopping mall performance.

## Objectives
- Analyze customer purchasing behavior
- Compare sales and revenue by gender
- Analyze purchasing patterns across age groups
- Identify high-performing product categories
- Analyze payment method preferences
- Compare shopping mall performance
- Generate business insights and recommendations

## Dataset
The dataset contains customer shopping transaction records from multiple shopping malls.

Key attributes include:
- Customer ID
- Invoice Number
- Gender
- Age
- Category
- Quantity
- Price
- Payment Method
- Invoice Date
- Shopping Mall

## Data Preparation
The data was prepared in Power BI through:
- Data import
- Data type verification
- Data cleaning
- Revenue calculation
- Age group creation
- Dashboard development

## Key Insights
- Female customers contributed a larger share of overall revenue.
- Clothing was the highest-performing product category.
- The 21–30 age group recorded the highest customer activity.
- Cash was the most frequently used payment method.
- Shopping mall performance varied across locations.
